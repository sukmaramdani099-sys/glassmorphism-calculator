# 🧮 Glassmorphism UI Calculator

Sebuah aplikasi web kalkulator sederhana dengan desain antarmuka modern menggunakan efek **Glassmorphism** dan **Dark Mode**. Dibuat murni menggunakan HTML, CSS, dan Vanilla JavaScript.

![Kalkulator Preview]([https://sukmaramdani099-sys.github.io/glassmorphism-calculator/])

## ✨ Fitur Utama
*   **Desain Modern:** Menggunakan efek kaca transparan (backdrop-filter) yang elegan.
*   **Responsif:** Tata letak rapi menggunakan CSS Grid.
*   **Logika Akurat:** Mampu melakukan operasi dasar matematika (+, -, ×, ÷) dengan Vanilla JavaScript.
*   **Penanganan Error:** Mencegah input ganda pada titik desimal dan operator.

## 🛠️ Teknologi yang Digunakan
*   **HTML5** (Struktur UI)
*   **CSS3** (Styling, Flexbox, CSS Grid)
*   **JavaScript (ES6)** (Logika DOM Manipulation)

## 🚀 Cara Menjalankan Secara Lokal
1. Clone repository ini: `git clone https://github.com/sukmaramdani099-sys/glassmorphism-calculator`
2. Buka file `index.html` di browser Anda, atau gunakan ekstensi **Live Server** di VS Code.
